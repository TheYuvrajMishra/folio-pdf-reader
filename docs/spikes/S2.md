# Spike S2 — Skia page curl shader + transition fallbacks

**Agent:** S2 · **Date:** 2026-10-17 · **Milestone:** M0
**Files:** `src/render/curl.ts`, `src/render/slide.ts`, `src/render/fade.ts`

## 1. What was built

- `src/render/curl.ts` — SkSL `RuntimeEffect` source (`CURL_SHADER_SOURCE`) implementing
  the cylinder-model page curl, plus a typed uniforms builder (`buildCurlUniforms`)
  and a pure drag→progress helper (`curlProgressFromDrag`). Framework-free apart
  from the `Uniforms` type import from `@shopify/react-native-skia`.
- `src/render/slide.ts` — framework-free slide spec: `slideFrameAt(t, pageWidth, direction)`
  returns per-frame `{ outgoingX, outgoingDim, incomingX, easedT }`.
- `src/render/fade.ts` — framework-free fade spec: `fadeFrameAt(t)` returns
  `{ outgoingOpacity, incomingOpacity }`, plus the reduced-motion 120 ms constant.

## 2. Curl shader design (cylinder model)

Coordinate space: device pixels of the page rect. Uniforms: `pageSize` (vec2),
`progress` 0..1, `curlRadius` px, `direction` ±1, `shadowStrength` 0..1, and two
`uniform shader` children — `frontPage` (current page, curls) and `backPage`
(next page, revealed underneath; bound as `<Shader>` children in declaration order).

Geometry (in a mirrored space where the free edge is always at x = W):
- `tipArc = p·(W + πr)` — arc length of lifted paper; `c = W − tipArc` — the tangent
  point where paper leaves the plane; `thetaTip = tipArc / r` — tip wrap angle.
- **Region 1 — the roll** (`xm ∈ (c, c+r]`): early curl (`thetaTip < π/2`) shows the
  front face bending away (angle-shaded); once folded, the visible branch is the
  back face (`θ = π − asin(s)`), sampled **mirrored** from the front texture and
  tinted ×0.88 (DESIGN.md §7: 12% darker), with `0.45+0.55·|cos θ|` roll shading
  (darkest at the silhouette) and a crease shadow near the tangent.
- **Region 2 — folded tip** (`thetaTip > π`): the tip folds back over the flat page.
  Deeper wraps pass *under* the first fold (lower z), so only the topmost fold
  layer (`θ = π + α`) is rendered — no loop needed.
- **Region 3 — flat front** (`xm ≤ c`): front texture with a soft gaussian shadow
  cast by the roll near the curl line (up to 38% darkening at the line).
- **Region 4 — revealed page** (`xm > c+r`): next-page texture with a soft shadow
  under the roll (up to 30%).
- Edge cases verified by hand: p=0 → fully flat (shadow terms → ~0); p=1 → roll and
  fold entirely off-screen, pure next page; backward direction mirrors geometry
  while texture sampling stays in device coordinates.

Back-face content choice: mirrored front-page sample × 0.88. Alternative (flat
paper-tint color) is a one-line change if on-device review prefers it.

## 3. Static review notes (no Skia runtime on this VM)

Checked against the installed `@shopify/react-native-skia@2.14.0` sources:
- Entry `vec4 main(vec2 fragcoord)` — the required RuntimeEffect signature.
- Uniforms declared **without initializers** (SkSL forbids them); `uniform shader`
  children sampled via `.eval(vec2)` — the documented child-sampling API
  (confirmed in the package's `ImageFilterFactory` docs).
- **No loops** (sidesteps SkSL's constant-bounds loop rule entirely), no arrays,
  no recursion, no `texture()`, no derivatives, no `discard`.
- All float literals carry decimal points (SkSL has no implicit int→float);
  all builtins used (`clamp/min/max/asin/sin/cos/exp/smoothstep/mix/abs`) are in
  the SkSL standard library.
- TS side: `buildCurlUniforms` returns the package's `Uniforms` type; value
  uniforms only (Skia's `getUniformCount()` excludes `uniform shader` children,
  which bind as `<Shader>` children instead). Strict TS, no `any`.

**Not verifiable here:** actual shader compilation (`Skia.RuntimeEffect.Make`
returns null + error string on failure — M2 must log that path), visual
correctness of the roll/fold math, and GPU frame time. The geometry was
hand-checked at p = 0 / 0.5 / 1 (see §2) but on-device review is mandatory.

## 4. Standing decision (per PRD §7.7)

**Slide/fade are the DEFAULT transitions; curl is EXPERIMENTAL** until on-device
60 fps numbers exist on a mid-range Android phone.

- Auto-downgrade rule (PRD §6.3): if frame-time p95 > 24 ms for 3 consecutive
  page turns, downgrade curl → slide and show a toast. M2 implements the
  frame-time sampler and the toast.
- If the curl shader fails to compile at runtime, fall back to slide (never crash
  the reader on a null RuntimeEffect).
- Reduced motion (OS "Remove animations" or in-app toggle) → all transitions
  become 120 ms fades; page animation forced to None unless the user overrides.

## 5. Full motion parameters (DESIGN.md §7, recorded for M2)

| Interaction | Spec |
|---|---|
| Page curl | finger-follow 1:1; commit if progress > 35% **or** fling > 800 px/s; settle spring `{damping: 20, stiffness: 180, mass: 1}` ≈ 420 ms; back face 12% darker; soft shadow along curl line |
| Page slide | outgoing translates 30% + dims 1 → 0.9; incoming translates 100%; 280 ms `cubic-bezier(0.2, 0.8, 0.2, 1)` |
| Page fade | 180 ms linear cross-fade |
| Reduced motion | everything → 120 ms fades; page animation = None |
| Chrome show/hide | opacity + 8 px translate, 180 ms ease-out |
| Ruler step | glide spring `{damping: 22, stiffness: 320}` ≈ 120 ms; light haptic tick (if on) |
| Ruler cross-page | page turn in chosen style; band fades in on first line after settle, 140 ms |
| Book open | cover shared-element scales to page 1 (320 ms), library fades |
| Annotation add | highlight "ink-in" wipe L→R 160 ms; pen live |
| Undo/redo | affected annotation fades out/in 140 ms; scroll into view if off-screen |
| Sheets | slide-up 260 ms spring, 40% scrim |
| List entrance | stagger 40 ms, translateY 12 → 0, opacity 0 → 1 |
| Resume chip | slide-down 200 ms, hold 2.5 s, fade 200 ms |

All animations run on the UI thread (Reanimated worklets / Skia shared values);
no JS-thread-driven frame updates.

## 6. "60 fps on mid-range Android" validation — DEFERRED

This VM has no Android device/emulator and cannot execute Skia shaders, so
**on-device fps cannot be measured here**. Validation is deferred to the v0.1.0
APK installed on the owner's phone (M2 exit criterion: 55+ fps sustained).
Per-pixel cost estimate for reviewers: worst case ~6 transcendentals + branches
per fragment — expected to be fine on mid-range Adreno/Mali, but the
auto-downgrade rule (§4) is the safety net, not this estimate.
